# 📚 통합 장르 키워드 사전 관리 센터 사용 설명서

본 문서는 **WebNovelManager**의 **「통합 장르 키워드 사전 관리 센터」** 기능에 대한 상세 사용법 및 실전 활용 가이드입니다.

---

## 1. 개요 및 사전의 역할

WebNovelManager의 장르 판정 엔진은 4단계 우선순위로 작동합니다:

1. **파일명 첨언/해시태그** (`[무협]`, `#패러디 #붕괴-스타레일` 등 최우선)
2. **웹 검색 엔진** (네이버 시리즈, 카카오페이지, 리디북스, 바이두 백과 등)
3. **중국어 음독 패턴 정밀 분석** (`아진몰상`, `이신몰상`, `천성` 등)
4. **로컬 키워드 사전 폴백 (Fallback)** (`genre_keywords.json`, 가중치 기반 점수 판정)

> 💡 **핵심 요약:**  
> 웹 검색이 불가능한 환경(오프라인, 비공식 번역본, 제목 축약본, 미등록 신작)이거나 검색 결과가 모호할 때, **사전에 등록된 키워드 가중치의 합산 점수**가 최종 장르를 결정합니다.  
> 따라서 사전을 잘 관리하면 웹 검색 없이도 **0.01초 만에 100% 정확한 자동 분류**가 가능해집니다.

---

## 2. 화면 구성 및 3대 핵심 탭

메인 윈도우 결과 테이블 상단의 **`[📚 사전 관리]`** 버튼을 누르면 관리 센터 모달 창이 열립니다.

### ① 상단 요약 통계 카드

- **총 등록 키워드**: 현재 사전에 등록된 전체 키워드 수 (기본 1,490여 개)
- **사전 버전 / 갱신일**: 현재 사전 버전(v1.6.x) 및 최종 수정 날짜
- **지원 장르 수**: 판정 가능한 장르 수 (총 15개 표준 장르)
- **축적 캐시 / 후보**: 웹 검색을 통해 축적된 캐시 데이터 건수 및 발굴 대기 후보 수

---

### ② 탭 1: 📖 등록 키워드 관리 (조회 / 검색 / 편집)

사전에 등록된 모든 키워드를 직접 확인하고 편집할 수 있는 공간입니다.

- **장르 필터 드롭다운**:
  - `[전체]`, `무협`, `현판`, `퓨판`, `선협`, `판타지`, `로판`, `언정`, `패러디`, `겜판`, `역사`, `스포츠`, `SF`, `밀리터리`, `공포`, `현대` 중 원하는 장르만 선택하여 조회
- **실시간 검색창**:
  - 특정 단어(예: `천마`, `화산`, `시스템`)를 입력하고 `Enter` 또는 `[검색]` 버튼 클릭 시 즉시 필터링
  - `[초기화]` 버튼 클릭 시 전체 목록으로 복귀
- **키워드 목록 테이블**:
  - **번호 / 키워드 / 소속 장르 / 가중치 (1~10) / 우선도 등급** 표시
  - 행을 **더블 클릭**하면 즉시 가중치 수정 창이 열립니다.
- **주요 조작 버튼**:
  - **`[➕ 키워드 추가]`**: 신규 키워드, 소속 장르, 가중치(1~10)를 지정하여 사전에 등록
  - **`[✏️ 가중치 수정]`**: 선택한 키워드의 가중치(1~10)를 변경
  - **`[🗑️ 선택 삭제]`**: 잘못 등록되었거나 불필요한 키워드를 사전에서 영구 삭제 (다중 선택 지원)

---

### ③ 탭 2: ⚡ 캐시 마이닝 & 자동 최적화 (자동 학습)

소설 정리 과정에서 누적된 웹 검색 캐시(`config/genre_cache.json`)로부터 고빈도 어휘 및 CJK 원문 쌍을 자동 발굴하여 사전에 반영합니다.

1. **`[🔍 1단계: 캐시 마이닝 실행]` 클릭**:
   - 백그라운드 스레드로 캐시 데이터를 정밀 분석하여 장르 독점도(Purity)와 빈도가 높은 키워드 후보를 도출합니다.
2. **후보군 검토 및 선별**:
   - 목록에서 원치 않는 일반 조사나 잡음 단어가 있다면 클릭하여 체크를 해제(` `)하거나,
   - 행을 선택 후 **`[🗑️ 후보 제외]`** 버튼을 눌러 목록에서 제거할 수 있습니다.
   - **`[✓ 전체 선택]`** / **`[✗ 선택 해제]`** 버튼으로 일괄 조작 가능
3. **`[⚡ 2단계: 선택 후보 사전 반영]` 클릭**:
   - 선택된 후보 키워드만 사전에 안전하게 병합 저장됩니다.
   - `[동기화 후 자동 회귀 검증(pytest) 수행]` 체크 시, 단위 테스트를 자동 수행하여 기존 분류 체계의 안전성을 확인합니다.

---

### ④ 탭 3: 🏷️ 특성/팬덤 & 음독 패턴 레퍼런스

시스템에 내장된 규칙 사전들을 한눈에 열람할 수 있는 참조 화면입니다.

- **패러디 팬덤 매핑**:
  - `붕괴: 스타레일`, `붕괴-스타레일`, `스타레일` $\rightarrow$ `붕괴 스타레일`
  - `나루토`, `원신`, `해리포터`, `명탐정 코난`, `블리치`, `주술회전` 등 표준 태그 변환 규칙 확인
- **핵심 특성 태그 (Trait)**:
  - `시스템`, `사합원`, `환생/빙의`, `전문직`, `먼치킨`, `귀환`, `힐링` 등 서브 태그 매칭 정규식 확인
- **중국어 음독 접두사 (CJK)**:
  - `이신몰상/아진몰상(我真没想)` $\rightarrow$ "내가 진짜 ~할 생각은 없었는데"
  - `천성/천서(穿成/穿书)` $\rightarrow$ "빙의/책빙의"
  - `별야(别惹)` $\rightarrow$ "~를 건드리지 마라" 등 번역투 직역 제목 규칙 확인

## 3. 가중치(Weight 1~10) 설정 가이드

키워드를 직접 등록할 때는 해당 단어가 장르를 얼마나 결정짓는지를 고려하여 가중치를 부여합니다.

| 등급 | 가중치 | 단어 성격 | 대표 예시 | 설정 요령 |
|:---:|:---:|:---|:---|:---|
| **⭐ 핵심** | **10** | **결정적 고유 어휘** | `천마`, `화산파`, `남궁세가`, `수선`, `황녀`, `재벌` | 제목에 이 단어가 있다면 사실상 해당 장르로 즉시 확정되는 어휘 |
| **🔷 주요** | **7 ~ 9** | **대표 장르 클리셰** | `내공`, `검법`, `마법사`, `각성`, `영지`, `성좌` | 해당 장르를 강력하게 시사하지만 다른 복합 장르에도 쓰일 수 있는 어휘 |
| **🔸 보조** | **4 ~ 6** | **보조/공용 어휘** | `귀환`, `회귀`, `천재`, `사냥`, `던전`, `막내` | 여러 장르에서 두루 사용되며, 다른 키워드와 합산되어 장르를 결정하는 어휘 |
| **▫️ 일반** | **1 ~ 3** | **경미한 단서** | `시작`, `인생`, `생존`, `도전` | 단독 결정력은 없으나 미약한 가산점을 보태는 어휘 |

---

## 4. 실전 활용 워크플로우 추천

### 시나리오 A: 대량 정리 후 사전 자동 진화 (Self-Learning)

1. 새로운 소설 수백 권을 평소처럼 웹 검색 모드로 정리합니다.
2. 정리가 끝난 후 **`[📚 사전 관리]` $\rightarrow$ `[⚡ 캐시 마이닝 & 자동 최적화]`** 탭으로 이동합니다.
3. **`[1단계: 캐시 마이닝 실행]`** 클릭 후, 후보 목록에서 이상한 단어만 제외하고 **`[2단계: 선택 후보 사전 반영]`**을 클릭합니다.
4. 내 수집 성향에 맞춘 최신 웹소설 어휘가 사전에 자동 축적되어, 다음 정리부터는 웹 검색 없이도 즉시 분류됩니다.

### 시나리오 B: 특정 소설이 오분류될 때 즉시 보정

1. 예: `[선협]` 소설인데 `[판타지]`로 잘못 분류되는 경우:
2. **`[📖 등록 키워드 관리]`** 탭에서 해당 소설 제목에 들어있는 주요 단어를 검색합니다.
3. 만약 엉뚱한 장르에 높은 가중치로 등록되어 있다면 **`[🗑️ 선택 삭제]`**하거나 가중치를 낮춥니다.
4. **`[➕ 키워드 추가]`**를 눌러 해당 단어(예: `탄서성공`)를 `선협` 장르에 **가중치 10**으로 등록합니다.
5. 저장 즉시 메모리 분류기에 반영되므로 프로그램을 재시작할 필요가 없습니다.

### 시나리오 C: 개인 맞춤형 특화 어휘 선제 등록

- 주로 읽는 특정 서브컬처 팬덤이나 특화 키워드가 있다면 미리 등록해 둡니다.
  - 예: `블루아카`, `원신`, `스타레일` $\rightarrow$ `패러디` (가중치 10)
  - 예: `사합원`, `지청` $\rightarrow$ `현판` (가중치 9~10)

## 5. 데이터 안전성 및 무결성 보장

- **이중 사전 파일 원자적 동기화 (Atomic Sync)**:
  - `modules/classifier/genre_keywords.json` 및 `modules/classifier/src/data/genre_keywords.json` 두 파일에 임시 파일 쓰기 후 `os.replace`로 동시 교체하므로 파일 손상이 발생하지 않습니다.
- **자동 백업 및 롤백 (`.bak`)**:
  - 변경 직전 이전 상태가 `.bak` 파일로 자동 백업되며, 쓰기 중 예외가 발생하면 즉시 이전 상태로 자동 복원됩니다.
- **실시간 메모리 리로드**:
  - 파일 저장 성공 시 백그라운드에서 싱글톤 인스턴스(`KeywordManager`)를 즉시 갱신하므로 메인 화면에서 재실행 없이 즉시 적용됩니다.
