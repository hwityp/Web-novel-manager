================================================================================
  WebNovelManager - 통합 장르 키워드 사전 관리 센터 사용 설명서
================================================================================

1. 개요 및 사전의 역할
--------------------------------------------------------------------------------
WebNovelManager의 소설 장르 판정 엔진은 다음 4단계 우선순위로 작동합니다:

  1순위: 파일명 첨언 / 해시태그 ([무협], #패러디 #붕괴-스타레일 등 최우선)
  2순위: 웹 검색 엔진 (네이버 시리즈, 카카오페이지, 리디북스, 바이두 백과 등)
  3순위: 중국어 음독 패턴 정밀 분석기 (아진몰상, 이신몰상, 천성 등)
  4순위: 로컬 키워드 사전 폴백 (genre_keywords.json, 가중치 기반 점수 판정)

[핵심 요약]
웹 검색이 불가능한 환경(오프라인, 비공식 번역본, 제목 축약본, 신간 소설)이거나
검색 결과가 애매할 때, 사전에 등록된 키워드 가중치 합산 점수가 최종 장르를 결정합니다.
사전을 잘 관리해두면 웹 검색 없이도 0.01초 만에 100% 정확한 자동 분류가 가능합니다.


2. 화면 구성 및 3대 핵심 탭
--------------------------------------------------------------------------------
메인 화면 결과 테이블 우측 상단의 [📚 사전 관리] 버튼을 클릭하면 대화상자가 열립니다.

[상단 요약 통계 카드]
  - 총 등록 키워드 : 현재 사전에 등록된 전체 키워드 수 (기본 1,490여 개)
  - 사전 버전 / 갱신일 : 현재 사전 버전(v1.6.x) 및 최종 수정 날짜
  - 지원 장르 수 : 판정 가능한 표준 장르 수 (총 15개 장르)
  - 축적 캐시 / 후보 : 웹 검색을 통해 축적된 캐시 건수 및 마이닝 대기 후보 수

--------------------------------------------------------------------------------
[탭 1: 📖 등록 키워드 관리 (조회 / 검색 / 편집)]
--------------------------------------------------------------------------------
사전에 등록된 모든 키워드를 직접 확인하고 편집(CRUD)할 수 있는 핵심 화면입니다.

  1) 장르 필터 드롭다운:
     - [전체] 및 15개 장르(무협, 현판, 퓨판, 선협, 판타지, 로판, 언정, 패러디 등)를
       선택하여 해당 장르의 키워드만 모아볼 수 있습니다.

  2) 실시간 검색창:
     - 검색어를 입력하고 Enter 또는 [검색] 버튼을 누르면 해당 어휘를 즉시 필터링합니다.
     - [초기화] 버튼을 누르면 전체 목록으로 돌아옵니다.

  3) 키워드 목록 테이블:
     - 번호, 키워드/어휘, 소속 장르, 가중치 (1~10), 우선도 등급이 표시됩니다.
     - 행을 더블 클릭하면 즉시 가중치 수정 팝업이 열립니다.

  4) 주요 조작 버튼:
     - [➕ 키워드 추가] : 신규 단어, 장르, 가중치(1~10)를 입력하여 사전에 등록합니다.
     - [✏️ 가중치 수정] : 선택한 키워드의 가중치(1~10)를 변경합니다.
     - [🗑️ 선택 삭제]   : 불필요한 키워드를 영구 삭제합니다 (다중 선택 지원).


--------------------------------------------------------------------------------
[탭 2: ⚡ 캐시 마이닝 & 자동 최적화 (자동 학습)]
--------------------------------------------------------------------------------
소설 정리 과정에서 누적된 검색 캐시(config/genre_cache.json)로부터 고빈도 어휘 및
CJK 한자 쌍을 자동 발굴하여 사전에 반영합니다.

  1) [🔍 1단계: 캐시 마이닝 실행] 클릭:
     - 백그라운드에서 캐시를 분석하여 출현 빈도와 순도(Purity)가 높은 후보를 추출합니다.

  2) 후보군 검토 및 선별:
     - 목록에서 원치 않는 일반 조사나 잡음 단어는 클릭하여 체크 해제([ ])하거나,
       선택 후 [🗑️ 후보 제외] 버튼을 눌러 목록에서 완전히 제거합니다.
     - [✓ 전체 선택] / [✗ 선택 해제] 버튼으로 일괄 조작할 수 있습니다.

  3) [⚡ 2단계: 선택 후보 사전 반영] 클릭:
     - 선택된 후보 키워드만 사전에 안전하게 병합 저장됩니다.
     - '동기화 후 자동 회귀 검증(pytest) 수행' 체크 시, 기존 규칙과의 충돌 여부를
       자동 검증한 뒤 안전하게 저장합니다.


--------------------------------------------------------------------------------
[탭 3: 🏷️ 특성/팬덤 & 음독 패턴 레퍼런스]
--------------------------------------------------------------------------------
시스템에 기본 내장된 규칙 사전들을 한눈에 열람할 수 있는 참조 화면입니다.

  1) 패러디 팬덤 매핑:
     - '붕괴: 스타레일', '붕괴-스타레일', '스타레일' -> '붕괴 스타레일'
     - 나루토, 원신, 해리포터, 코난, 블리치 등 표준 태그 변환 규칙 확인
  2) 핵심 특성 태그 (Trait):
     - 시스템, 사합원, 환생/빙의, 전문직, 먼치킨 등 서브 태그 매칭 정규식 확인
  3) 중국어 음독 접두사 (CJK):
     - 이신몰상/아진몰상(我真没想), 천성/천서(穿成/穿书), 별야(别惹) 등 번역투 규칙 확인


3. 가중치(Weight 1~10) 설정 요령
--------------------------------------------------------------------------------
키워드를 새로 등록하거나 수정할 때는 단어의 장르 결정력에 따라 점수를 부여합니다.

  [10점 (⭐ 핵심)]
    - 결정적 고유 어휘: 천마, 화산파, 남궁세가, 수선, 황녀, 재벌
    - 제목에 이 단어가 들어가면 사실상 99% 해당 장르로 확정되는 어휘입니다.

  [7~9점 (🔷 주요)]
    - 대표 장르 클리셰: 내공, 검법, 마법사, 각성, 영지, 성좌
    - 해당 장르의 대표적 소재이나 다른 복합 장르에도 혼용될 수 있는 어휘입니다.

  [4~6점 (🔸 보조)]
    - 보조 / 공용 어휘: 귀환, 회귀, 천재, 사냥, 던전, 막내
    - 여러 장르에서 두루 쓰이며, 다른 키워드와 합산되어 장르를 결정합니다.

  [1~3점 (▫️ 일반)]
    - 경미한 단서: 시작, 인생, 생존, 도전
    - 단독 결정력은 없으나 미약한 가산점을 보태는 어휘입니다.


4. 실전 활용 워크플로우 3가지
--------------------------------------------------------------------------------
[시나리오 A: 대량 정리 후 사전 자동 진화 (Self-Learning)]
  1. 수백 권의 소설을 평소처럼 웹 검색 모드로 정리합니다.
  2. 정리가 끝난 후 [📚 사전 관리] -> [⚡ 캐시 마이닝] 탭으로 이동합니다.
  3. [1단계: 캐시 마이닝] -> 잡음 단어 제외 -> [2단계: 선택 후보 사전 반영] 클릭!
  4. 내 수집 성향에 맞춘 최신 어휘가 사전에 자동 축적되어 이후 처리가 매우 빨라집니다.

[시나리오 B: 특정 소설이 오분류될 때 즉시 보정]
  1. [선협] 소설인데 [판타지]로 잘못 분류된 경우,
  2. [📖 등록 키워드 관리] 탭에서 해당 제목의 주요 단어를 검색합니다.
  3. 엉뚱한 장르에 잘못 등록된 단어가 있다면 삭제하거나 가중치를 낮춥니다.
  4. [➕ 키워드 추가]를 눌러 해당 단어(예: '탄서성공')를 [선협]에 가중치 10으로 등록합니다.
  5. 저장 즉시 메모리에 반영되므로 프로그램을 재시작할 필요가 없습니다.

[시나리오 C: 개인 맞춤형 특화 어휘 선제 등록]
  - 주로 수집하는 작가명, 서브컬처 팬덤, 세계관 용어를 미리 등록해 둡니다.
    예: '블루아카', '원신', '스타레일' -> [패러디] (가중치 10)
    예: '사합원', '지청' -> [현판] (가중치 10)


5. 데이터 안전성 및 무결성 보장
--------------------------------------------------------------------------------
  - 이중 JSON 원자적 동기화: 임시 파일 교체(Atomic Write)로 파일 손상을 방지합니다.
  - 자동 백업 및 롤백: 변경 전 상태를 .bak 파일로 자동 백업하며 오류 시 자동 복원됩니다.
  - 실시간 메모리 리로드: 파일 저장 즉시 현재 실행 중인 프로그램에 실시간 반영됩니다.
