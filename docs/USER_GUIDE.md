> **버전**: v1.3.61  
> **최종 갱신일**: 2026-10-15  
> **대상**: 웹소설 수집가, 아카이브 관리자, 대용량 번역본/TXT 정리 사용자

## 1. 개요 및 핵심 진화 내역

**WNAP (Web Novel Archive Pipeline)**은 웹소설 텍스트 파일(TXT) 및 압축 아카이브(ZIP, RAR, 7Z, ZIPX)를 분석하여 **순수 제목 추출(Title Anchor)**, **원산지(국내/중국/일본) 판정**, **장르 분류 및 다중 특성 태그 추출**, **한국 표준 맞춤법 기반 파일명 정규화**를 전자동으로 수행하는 고성능 파이프라인 관리 도구입니다.

### 🌟 v1.3.61 주요 핵심 기능

1. **7단계 직관적 독립 GUI 파이프라인**: 스캔, 추론, 정규화, 실행 각 단계의 완전한 결합 해제(Decoupling) 및 원클릭 일괄 처리 제공.
2. **한자어 음운변화 및 한국식 독음 오기 자동 교정 엔진**: 두음법칙, 렬/열, 율/률, 不(부/불) 음운변화, 관용음 및 활음조를 어문 규정에 맞춰 정밀 자동 교정.
3. **중국/일본 소설 초고속 패스트패스 & 조합형 제목 분해**: 네트워크 검색 없이 0.02초 만에 음독/클리셰를 감지하고 `[독음: 번역]` 형태의 복합 제목을 자동 분해 및 캐싱.
4. **다중 특성 태그 스마트 보강**: `[언정, 연대물, 공간]`, `[현판, 연대물, 재테크]` 등 단일 장르를 풍부한 메타데이터 복합 태그로 확장.

## 2. 화면 구성 및 7대 핵심 버튼 가이드

WNAP 메인 윈도우는 상단의 경로 제어 패널, 중앙의 작업 제어 7버튼 바, 하단의 작업 테이블과 로그 콘솔로 구성되어 있습니다.

```text
┌────────────────────────────────────────────────────────────────────────┐
│ 📂 원본 폴더 [ D:\WebNovels\Downloads ] [찾아보기]                     │
│ 📁 대상 폴더 [ D:\WebNovels\Organized ] [찾아보기]                     │
├────────────────────────────────────────────────────────────────────────┤
│ [1. 폴더 스캔] [2. 장르 추론] [3. 파일명 정규화] [4. 정규화 실행]     │
│ [소스에 즉시 반영]         [⚡ 일괄 처리]         [↺ 초기화]          │
├────────────────────────────────────────────────────────────────────────┤
│  상태  │  원본 파일명          │  추출 제목     │   장르   │  신뢰도  │ 정규화 파일명 │
│  대기  │  쾌천녀배랭정점.txt   │ 쾌천여배냉정점 │   언정   │   high   │ [언정] 쾌... │
└────────────────────────────────────────────────────────────────────────┘
```

### 🔘 7대 조작 버튼 상세 설명

| 단계 | 버튼 명칭 | 역할 및 동작 원리 | 추천 실행 시점 |
| :---: | :--- | :--- | :--- |
| **Step 1** | **`1. 폴더 스캔`** | 지정된 원본 폴더 내 파일 목록을 탐색하고, 회차/용량/첨언 등 기초 메타데이터를 파싱하여 테이블에 로드합니다. (장르 추론과 정규화는 실행하지 않고 원본 정보만 로드) | 신규 폴더를 처음 열었을 때 |
| **Step 2** | **`2. 장르 추론`** | 기존 파일명 첨언 태그, 로컬 음독 패스트패스, 장르 캐시, 네이버/구글 검색 및 플랫폼 크롤링을 순차 실행하여 **국적(CN/KR/JP) 판별 및 장르를 확정**합니다. | 장르가 없거나 미분류 파일이 많을 때 |
| **Step 3** | **`3. 파일명 정규화`** | 현재 설정된 장르와 표준 표기 규칙(두음법칙 교정, 특수문자 정리, 회차 표기 표준화)을 적용하여 **'정규화 파일명' 컬럼에 변경될 이름을 미리보기로 생성**합니다. | 2단계 후 또는 장르를 수동 편집한 후 |
| **Step 4** | **`4. 정규화 실행`** | 생성된 미리보기 이름을 기반으로 **대상 폴더(Target)에 장르별 하위 폴더를 자동 생성하고 복사/이동**합니다. 원본 파일은 그대로 안전하게 보존됩니다. | 정규화된 파일들을 별도 정리 폴더로 모을 때 |
| **즉시** | **`소스에 즉시 반영`** | 대상 폴더로 복사하지 않고, **원본 폴더 내에서 파일명을 직접 정규화 파일명으로 인플레이스(In-place) 변경**합니다. | 다운로드 폴더 자체의 이름을 깔끔히 고치고 싶을 때 |
| **원클릭** | **`⚡ 일괄 처리`** | `스캔 ➔ 장르 추론 ➔ 정규화 미리보기 ➔ 확인 팝업 ➔ 정규화 실행`을 클릭 한 번으로 전자동 연속 실행합니다. | 확인 작업 없이 빠르게 전체 작업을 끝내고 싶을 때 |
| **리셋** | **`↺ 초기화`** | 현재 테이블과 파이프라인 작업 상태를 깨끗이 비우고 초기 상태로 되돌립니다. | 다른 폴더 작업을 시작할 때 |

## 3. 핵심 기능 상세 안내

### ① 한자어 음운변화 및 한국식 독음 오기 정밀 교정

중국·일본 소설의 기계번역 또는 한국식 한자 독음 오역으로 인해 맞춤법이 어긋난 제목을 국립국어원 한국어 어문 규정에 따라 자동 교정합니다.

1. **不 → 부 / 불 음운변화 (한글 맞춤법 제12항)**:
   - ㄷ, ㅈ 앞에서는 **'부'**: `불동산` → `부동산`, `불정부패` → `부정부패`, `불당` → `부당`, `불실` → `부실`, `불조리` → `부조리`
   - 기타 자음/모음 앞에서는 **'불'**: `부멸` → `불멸`, `부사조` → `불사조`, `부패신화` → `불패신화`, `부굴` → `불굴`
2. **열/렬 (列/烈/裂) 및 율/률 (率/律) 규칙 (제11항 붙임 1)**:
   - 모음 또는 'ㄴ' 받침 뒤: **'열/율'** (`나렬` → `나열`, `분렬` → `분열`, `비률` → `비율`, `선률` → `선율`)
   - 그 외 자음 받침 뒤: **'렬/률'** (`행열` → `행렬`, `결열` → `결렬`, `법율` → `법률`, `능율` → `능률`)
3. **어두 두음법칙 안전 교정 (제10항, 제11항)**:
   - `룡` → `용`: `룡왕전설` → `용왕전설`, `룡제` → `용제`
   - `녀` → `여`: `녀배` → `여배`, `녀제` → `여제`, `녀신` → `여신`, `녀주` → `여주`
   - `년` → `연`: `년대문` → `연대문` (단, `백 년`, `70년대` 등 수사/의존명사는 본음 보존)
   - `랭` → `냉`: `랭정` → `냉정`, `랭혹` → `냉혹`, `랭담` → `냉담`, `랭혈` → `냉혈`
   - `래` → `내`: `래일` → `내일`, `래세` → `내세`
   - `락` → `낙`: `락원` → `낙원`, `락화` → `낙화`
   - `라` → `나`: `라열` → `나열`, `라침반` → `나침반`
4. **관용음 및 활음조 자동 교정**:
   - `희노애락` → `희로애락`, `승락` → `승낙`, `허낙` → `허락`, `토노` → `토로`, `모함` → `모략`
5. **외래어 및 고유명사 침범 방지 안전 가드**:
   - `로열(Royal)`, `로봇(Robot)`, `로맨스(Romance)`, `레벨(Level)` 등 외래어는 두음법칙 교정에서 완벽히 제외.
   - 중국 고유 호칭인 `대노(大佬)`, `니문(你们)` 등은 왜곡 없이 그대로 보존.

---

### ② 중국 소설 특화 최적화 (Fast-Path & 조합형 분해)

- **로컬 패스트패스 (<50ms)**:
  - 《풍비사숙저살풍료》, 《단총교처》, 《사합원》 등 중국 특유의 음독 어휘나 전각 문장부호(`，`, `：`)가 감지되면 인터넷 검색 없이 0.02초 만에 `선협`, `언정`, `현판` 등으로 고신뢰도 직행합니다.
- **`[독음: 번역]` 병렬 조합형 제목 분해**:
  - `단총교처：아대공간물자천칠령(70년대로 천월)`과 같이 독음과 한국어 번역이 병기된 제목을 자동으로 분해하여 독음 단독 또는 번역 단독 검색 시에도 동일한 캐시와 정확도를 보장합니다.
- **중국 소설 장르 통일 규칙**:
  - 중국 소설의 경우 서양식 판타지가 섞이지 않은 로맨스/로판 표기는 모두 **`언정(言情)`**으로 일관성 있게 자동 통합됩니다.

---

### ③ 다중 특성 태그 스마트 보강

단순한 1차원 장르(예: `[언정]`) 대신 독자의 취향을 반영하는 복합 태그(메인 1개 + 서브 특성 최대 2개)를 구성합니다.

- `년대문, 경영·중생` ➔ **`[현판, 연대물, 재테크]`**
- `년대문, 군혼 로맨스` ➔ **`[언정, 연대물, 군혼 로맨스]`**
- `차원이동 공간물 칠령` ➔ **`[언정, 연대물, 공간]`**
- `나루토 패러디 상태창` ➔ **`[패러디, 나루토, 시스템]`**
- `사합원 도시 회귀` ➔ **`[현판, 사합원]`**

## 4. 💡 효과적인 실전 사용 팁 (Pro Tips)

### 팁 1. 이미 태그가 붙은 대량의 소설을 1초 만에 파일명 정리하기

다운로드받은 파일명에 이미 `[무협]`, `[로판]`, `[언정]` 등의 장르 태그가 잘 붙어 있다면, 굳이 시간 소모가 있는 `2. 장르 추론(웹 검색)`을 누를 필요가 없습니다.

> **초고속 워크플로우:**  
> **`1. 폴더 스캔`** ➔ **`3. 파일명 정규화`** ➔ **`소스에 즉시 반영`**  
> (300개 파일 기준 약 **1초 만에** 모든 파일의 특수문자, 띄어쓰기, 두음법칙 교정이 완료됩니다.)

---

### 팁 2. 중국 번역 소설(치뎬/진장 소설)이 섞여 있을 때

중국 소설은 국내 포털(네이버/구글)에 정식 출간되지 않아 검색 시 미분류가 되기 쉽습니다.

- WNAP는 파일명에 한자가 없더라도 본문 앞부분(최대 4KB)의 번역 시그니처(`[딩!]`, `시스템 바인딩`, `숙주`, `초보자 패키지` 등)를 읽어 자동으로 **`CN(중국 소설)`**로 판별합니다.
- 따라서 웹 검색 쿼리도 일반 검색 대신 `중국 소설`, `치뎬`, `바이두 백과` 타깃 검색으로 스마트 전환되어 분류 성공률이 극대화됩니다.

---

### 팁 3. 안전한 정리 (타겟 복사 vs 소스 즉시 반영 선택 기준)

| 작업 방식 | 추천 상황 | 특징 |
| :--- | :--- | :--- |
| **`4. 정규화 실행`** (타겟 폴더 이동) | 라이브러리 전체 백업 및 영구 보관용 아카이빙 시 | 원본 파일이 전혀 손상되지 않으며, 타겟 폴더에 장르별(`[무협]`, `[판타지]` 등) 폴더가 자동 생성되어 분류 복사됨 |
| **`소스에 즉시 반영`** (In-place Rename) | 다운로드 폴더나 읽기 전용 기기(전자책/스마트폰)에 넣기 전 | 추가 디스크 용량을 차지하지 않고 현재 위치에서 파일명만 깔끔하게 표준 이름으로 변경 |

---

### 팁 4. 장르 수동 편집과 "자물쇠(User-Edited)" 잠금 보호

테이블에서 특정 소설의 장르를 사용자가 직접 수정(우클릭 ➔ `🏷️ 장르 편집` 또는 행 더블클릭)하면, 시스템은 해당 항목을 **사용자 편집 모드(`user_edited = True`)**로 보호합니다.

- 이후 `2. 장르 추론`이나 `⚡ 일괄 처리`를 다시 실행하더라도 **사용자가 정한 장르가 절대 덮어씌워지지 않고 영구 보존**됩니다.

---

### 팁 5. 오프라인 속도를 비약적으로 높이는 「캐시 마이닝」

인터넷 검색을 통해 분류된 소설들의 데이터는 `config/genre_cache.json`에 지속적으로 누적됩니다.

1. 테이블 상단의 **`[📚 사전 관리]`** 버튼을 클릭합니다.
2. **`⚡ 캐시 마이닝 & 자동 최적화`** 탭으로 이동합니다.
3. **`[🔍 1단계: 캐시 마이닝 실행]`**을 누르고, 발굴된 고빈도 어휘를 **`[사전에 반영]`**합니다.
4. 이렇게 학습된 키워드는 다음 정리 작업부터 인터넷 검색 없이 **0.001초 만에 로컬에서 즉시 분류**됩니다.

---

### 팁 6. 구글 API 키와 네이버 검색 API 설정으로 쿼터 오류 방지

- WNAP는 네이버 검색 API와 Google Custom Search API를 지원합니다.
- 프로젝트 루트의 `.env` 파일에 발급받은 API 키를 등록해 두면, IP 차단이나 크롤링 제한 없이 안정적이고 신속한 웹 검색을 이용할 수 있습니다.

```env
NAVER_CLIENT_ID=your_naver_id
NAVER_CLIENT_SECRET=your_naver_secret
GOOGLE_API_KEY=your_google_key
GOOGLE_CSE_ID=your_cse_id
```

## 5. 자주 묻는 질문 (FAQ)

### Q1. "미분류"로 나오는 파일은 어떻게 처리해야 하나요?

> 신작이거나 제목이 심하게 변형된 경우 웹 검색에서 일치하는 정보를 찾지 못할 수 있습니다.  
>
> 1. 테이블에서 해당 항목을 마우스 우클릭 후 **`🏷️ 장르 편집`**을 선택하여 올바른 장르를 직접 지정하세요.  
> 2. 저장 즉시 캐시에 등록되며, 이후 동일한 제목이나 변형 제목이 들어오면 자동으로 기억하여 분류합니다.

### Q2. 원본 파일의 회차나 부제 정보가 사라지지 않나요?

> 사라지지 않습니다. 타이틀 앵커 엔진은 `1-500`, `1부 24화`, `(완)`, `+ 외전` 등의 권수/회차/상태 표기를 정밀하게 분리한 후, 표준 정규화 형식(예: `[장르] 제목 1-500 (완) + 외전.txt`)에 맞춰 가장 단정하고 통일된 위치로 재배치합니다.

### Q3. 압축 파일(ZIP, RAR, 7Z)도 지원되나요?

> 네, 압축 파일 내부에 들어있는 TXT 파일의 구조를 분석하여 최적의 방식으로 해제하거나 개별 추출하여 동일하게 정규화 파이프라인을 적용합니다. (내부 텍스트 파일이 1개인 경우 단일 TXT로 안전 추출)
